Скачивайте исходники прямо в проект

YDL — приложение collblock для Windows, которое скачивает файлы и папки по ссылкам на Яндекс Диск и Google Диск. Выберите папку на компьютере, чтобы сохранить файлы по отдельности с исходной структурой.

Продолжить загрузку

YDL сохраняет частично скачанные файлы. Вернитесь к задаче после паузы из истории.

Выбрать исходники по монтажу

Импортируйте XML или EDL, чтобы скачать нужные клипы, или отфильтруйте файлы по формату.

Открыть ссылку в браузере

Расширение добавляет открытую ссылку в очередь после вашего подтверждения.

Доступ к Google Диску

YDL сначала проверяет, доступна ли ссылка без входа. Для закрытых ссылок YDL предлагает войти через Google и запрашивает доступ на чтение. Он нужен, чтобы перечислить файлы во вложенных папках выбранной ссылки и скачать их на ваш компьютер. YDL не меняет файлы на Google Диске и не использует Google API для создания, обработки или распространения интимных изображений без согласия, в том числе созданных ИИ.
