Скорость и лимиты Google Диска

Когда вы скачиваете открытый файл без входа, YDL обращается к Google Drive API со встроенным ключом. У этого ключа общая квота проекта. Свой ключ пригодится, если Google ограничил запросы общего проекта.

Если загрузка идёт медленно

Проверьте, как быстро тот же файл скачивается в браузере. На скорость влияют сеть, VPN и ограничения самой ссылки. Если YDL сообщает об ограничении публичных загрузок, попробуйте позже или подключите свой ключ.

Как получить свой ключ

  1. Откройте Google Cloud Console и создайте свой проект или выберите существующий.
  2. В выбранном проекте откройте Google Drive API и нажмите Enable.
  3. Откройте Credentials и выберите Create credentials → API key. В настройках ключа, в разделе API restrictions, оставьте доступ только к Google Drive API и сохраните.
  4. Скопируйте ключ и вставьте его только в YDL. Откройте Настройки → Свой ключ Drive API, нажмите Сохранить ключ и повторите загрузку. Эта настройка появилась в 3.0 Beta 9.

Ключ хранится на вашем компьютере под защитой Windows. В тех же настройках можно вернуться к встроенному ключу. Для закрытой ссылки по-прежнему понадобятся доступ к файлу и вход через Google.
