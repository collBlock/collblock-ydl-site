collblock YDL Русский

Browser extension

Manual installation for testers. First install YDL 3.0 Beta 6 or later on Windows.

  1. Open chrome://extensions in Chrome or browser://extensions in Yandex Browser.
  2. Turn on Developer mode and select Load unpacked. Choose %LOCALAPPDATA%\Programs\CollblockYDL\browser-extension, or the browser-extension folder under your custom install location.
  3. Open a shared cloud link and select Add. You can pin YDL from your browser's extensions menu.

To show a badge instead of a prompt, open the extension menu and turn on Badge only.

If your browser blocks unpacked extensions, wait for the store version.
