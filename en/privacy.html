YDL Privacy Policy

YDL is a Windows app developed by collblock. This policy covers the app, its browser extension, and this website.

Google Drive data and why YDL needs it

For links you add, YDL reads file and folder IDs, names, types, sizes, checksums when available, and nested folder structure. This information lets you review the queue, see how much space you need, select files, and preserve their folder structure. When you start a download, YDL reads the selected files and saves them to the folder you choose.

For restricted links, YDL requests drive.readonly permission. You sign in and grant consent on Google's website. The permission can read files available to your account, and YDL uses it when handling the links you add. YDL does not receive your Google password or ask for write access.

Storage and sharing

YDL and its bundled rclone utility connect directly to Google. Access and refresh tokens are stored in a directory in your Windows user profile with restricted access. If you supply your own Drive API key, YDL stores it using Windows data protection. Download links, options, and history are stored in your local profile. Downloaded files stay in your selected folder. History remains on your computer until you delete its entries.

YDL does not send Google Drive data or OAuth tokens to the developer and does not use them for advertising, resale, model training, or content generation. YDL's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Revoke YDL's access from your Google Account connections. Remove entries in YDL's download history to delete those local records. You can delete downloaded files from the destination folder in Windows.

Browser extension and website

The extension recognizes Yandex Disk and Google Drive links on the open page. When you confirm, it sends the link to your local YDL app. The badge preference is stored in your browser. The extension does not receive Google tokens.

This public website is hosted on GitHub Pages and is accessible without sign-in. GitHub handles requests to the website under its privacy statement. The app does not currently send usage statistics. Before enabling reporting, we will explain exactly what is sent and ask for separate consent in the app.

Changes and contact

The current policy is published here. If the way YDL uses Google data changes, YDL will notify you and ask for consent before applying the changes. Contact collblock, the developer, with privacy questions.
