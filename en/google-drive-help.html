Google Drive limits and speed

For public downloads, YDL uses a built-in Google Drive API key with a shared project quota. A personal key can help if Google limits requests from the shared project.

Slow downloads

Try downloading the same file in your browser. Network conditions, your VPN, and restrictions on the shared link can also affect speed. If YDL reports that public downloads are limited, try later or use your own key.

Get a personal API key

  1. Open the Google Cloud console and create or select a project.
  2. In that project, open Google Drive API and select Enable.
  3. Open Credentials and select Create credentials → API key. Under API restrictions, restrict the key to Google Drive API and save.
  4. In YDL 3.0 Beta 9 or later, open Settings, enter the key under Personal Drive API key, save it, and retry the download.

Windows protects the key on your computer. You can switch back to the built-in key in the same settings. Restricted links still require file access and Google sign-in.
